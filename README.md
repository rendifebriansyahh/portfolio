
portfolio-rendi-final-v3

Based on portfolio-rendi-final-v2, updated with purple-blue aurora background (reactive to mouse), full pages, dummy projects, Poppins font, Tailwind v3, Framer Motion integrated.

Install (pnpm recommended):
1. pnpm install
2. pnpm run dev

Or:
npx pnpm install
npx pnpm dev

Open http://localhost:5173
